## Huecos sin skill fiable

No se ha inventado ninguna skill. Estos huecos se buscaron en GitHub y no hay un pack reputado, con licencia clara y calidad suficiente:

- **SDK y certificación de YouTube Playables**. Playgama ya está cubierto con `playgama-bridge` y `playgama-publish` (oficiales). Para YouTube Playables no hay skill fiable: `martinalmeida/playables-youtube-sdk` (MIT, 0 estrellas, depende de su plantilla) queda en prueba; `hungify/playables-skills` y `popey/gamedev.sh-skills` no tienen LICENSE. Se sigue la documentación oficial y el Test Suite de Google.
- **Analítica fuera de Playgama (YouTube Playables, D1/D7 propios)**. En Playgama ya se cubre con `playgama-metrics-snapshot` y `game-engagement-ideas`.
- **Skill dedicada de accesibilidad** (WCAG, daltonismo, remapeo, subtítulos). No hay una skill standalone fiable. Se cubre en parte con `auditing-game-screen-readability`, `difficulty-and-balancing` (ayudas) y la ya instalada `game-ui-ux`.
- **Animación esquelética tipo Spine** y **sprites 3D prerenderizados a 2D**. No hay skill fiable con licencia clara. Para 3D web se sigue usando `skills-arte/threejs-skills`. Babylon.js: sin skill fiable.
- **Patrones TypeScript avanzados fuera de Phaser**. El pack `Yakoub-ai/phaser4-gamedev` tiene GDD, móvil y un harness Playwright, pero sigue sin LICENSE; no se instala nada más de ahí.
